A delivery invoice creation and journal entry tool designed specifically for Japanese-speaking rice farmers.

これは日本語話者で米作農家専用の納品書作成と仕訳を行うツールです。

緑のcodeの所を押してDownlordZipってやつを選べばダウンロードできます

使い方

（準備編）

1.下のタブで相手先マスタを開いて売り先、買い先、両方入力しましょう。

2.科目マスタを見て勘定科目を入れておきましょう

3.納品請求書タブを選んでまずはM11の所に納品請求書を吐き出したい場所をパスで指定しましょう

4.売るものの品名をT列に書いておきましょう

（売上があった編）

1.納品請求書タブで黄色いところ、つまりM2に売った日付を書きいれます。終わったらｴﾝﾀｰです

2.売り先を入れます。画面左を見たら名前とコードがずらっと並んでます、コードを選んでください。終わったらｴﾝﾀｰです

3.売り物のコードを入力、ｴﾝﾀｰです。数量を入れます。ｴﾝﾀｰです。単価を入れます、ｴﾝﾀｰです。重さを入れます、ｴﾝﾀｰです。

4.同じようにして他の売ものがあれば入力してください。

5.消費税ありの場合は、米（送料、精米代込み）とすれば徴収する売上は全部軽減税率になります27/4/1~1％、それまでは8％です。

（費用が発生した編）

1.仕訳入力タブを開きましょう、課税か非課税かでシートが違います

2.日付を入れてｴﾝﾀｰ

3.相手先を入れるか選ぶかしてｴﾝﾀｰ

4.科目を入れるか選ぶかしてｴﾝﾀｰ

5.適用、中身の説明を入れてｴﾝﾀｰ

6.外税表示なら税抜き価格を入れてｴﾝﾀｰ、税率を選んでｴﾝﾀｰ

7.内税表示なら税抜き価格を入れずにｴﾝﾀｰ、税込み価格を入れてｴﾝﾀｰ、税率を選んでｴﾝﾀｰ

これで入力できます。Etaxの時には費用は費用で合計して売り上げは売上で合計して入れたらいいです。
